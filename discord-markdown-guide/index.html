Discord Markdown

What Discord formats, what it ignores, and what needs conversion before you paste.

Supported formatting

Discord supports emphasis, headings, quotes, lists, code, spoilers, and masked links. Its syntax is similar to Markdown, but it does not follow CommonMark exactly.

Discord formatting syntax
FormatSyntax
Bold**bold**
Italic*italic*
Underline__underline__
Strikethrough~~old~~
Spoiler||hidden||

Inline code`code`
Masked link[label](https://example.com)
CommonMark difference

__Important__ means bold in CommonMark and underline in Discord. Use **Important** to preserve the CommonMark meaning.

Unsupported syntax

These common documentation features have no native Discord equivalent.

Tables
Convert them to an aligned code block or short labeled rows.
Task checkboxes
Use ☑ and ☐. Discord does not create interactive boxes.
Markdown images
Keep the image URL visible or use a masked link.
LaTeX and Mermaid
Keep the source in inline or fenced code.
Footnotes and references
Resolve them into ordinary links and notes.
Raw HTML
Keep the readable text. Discord does not render arbitrary HTML.

Message limits

Ordinary Discord messages are limited to 2,000 characters. Splitting at an arbitrary character can break links, emphasis, lists, Unicode sequences, or fenced code.

Split at paragraph and list boundaries where possible. If a code block crosses a boundary, close the fence in the first message and reopen it with the same language in the next.

Mentions

Text containing @everyone, @here, or structured user and role mentions can notify people when pasted.

Bots should restrict Discord's allowed_mentions payload. Clipboard tools cannot set that option, so active mention tokens should be neutralized before copying.

Conversion

  1. Parse CommonMark and only the GFM extensions you support.
  2. Transform the syntax tree instead of replacing text with broad regular expressions.
  3. Resolve unsupported structures with consistent rules.
  4. Neutralize active mentions outside code.
  5. Split at structural boundaries and validate every message.
