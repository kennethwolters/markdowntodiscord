Common questions

Markdown to Discord, without surprises.

Does Discord support Markdown?

Discord supports a useful subset, but not GitHub tables, task lists, HTML, or LaTeX. This converter turns unsupported structures into readable Discord text.

What happens above 2,000 characters?

The result is split into numbered messages while keeping Unicode characters and code fences intact. Copy and send each message in order.

Can this trigger mentions?

Potentially active user, role, @everyone, and @here mentions are neutralized by default. You can deliberately turn that protection off.

Is pasted Markdown uploaded?

No. Conversion and optional draft storage happen locally in your browser. Clearing the draft removes the locally saved text.
